# 🎓 Kids Learning SPA Collection

Offline, single-file, gamified learning apps for elementary students (Grade 5/6, Canadian Curriculum) — built with plain **HTML + CSS + inline JavaScript**. No build tools, no server, no internet required. Just open a file in your browser and learn.

## ✨ What's Inside

- 📚 **Subject-based lessons** — Math and Science concepts explained in simple, non-native-English-friendly language.
- 🎮 **Gamified learning** — quizzes, matching games, and interactive challenges for each concept.
- 📊 **Progress dashboard** — a central `dashboard.html` tracking scores and completed modules (via browser `localStorage`).
- 🧳 **Fully portable** — each lesson is a single `.html` file. Copy it anywhere, double-click, and it runs.

README.md

## 🚀 How to Use

1. Clone or download this repo.
2. Open `dashboard.html` in any modern browser to see all available lessons.
3. Click a lesson to open it, or navigate to `/Subject/filename.html` directly.
4. No installation, no dependencies, works fully offline.

## 🧭 Curriculum Scope

Content is designed for **elementary grades up to Grade 5/6**, aligned with the **Canadian Curriculum**.
